# Adopters

Organizations and projects using `dbmask` — in production, in test-data
pipelines, or in evaluation. Being listed here helps other teams judge
maturity, and helps maintainers prioritize what real deployments need.

**To add yourself:** open a pull request adding one row, or — if you prefer
not to PR — open an [adopter feedback issue](https://github.com/sealandseacat/dbmask/issues/new?template=adopter_feedback.yml)
and we'll add you (or keep you anonymous and record only the use case).

Entries are voluntary and self-reported. "Anonymous (industry)" entries are
verified privately by a maintainer before being added.

## What counts as adoption?

Any real use beyond a quick look: masking a staging refresh, a CI job that
validates masked snapshots, an internal evaluation that led to a decision
(even "not yet — because X" is valuable feedback; please tell us the X via
the [adopter feedback template](https://github.com/sealandseacat/dbmask/issues/new?template=adopter_feedback.yml)).
